# in-situ-lobster-microbiome

Code for analyzing the 16S amplicon data from American lobsters captured in situ. The core microbiome is analyzed in core.R and the predicted function of the core analyzed via Picrust2 in core_picrust.R. The manuscript is in preparation. Raw data are not public yet. 


Host microhabitats and embryogenesis dictate microbial community composition and predictive function in American lobsters (Homarus americanus)
